# causal_analysis
Objetivos

Ao final deste projeto, será possível:

Distinguir perguntas preditivas de perguntas causais, compreendendo que elas exigem formas diferentes de raciocínio e análise.

Reconhecer por que correlações e modelos preditivos, mesmo quando bem ajustados, não são suficientes para responder perguntas causais.

Entender o papel da inferência causal no suporte à tomada de decisão, especialmente em contextos que envolvem ações, intervenções ou políticas.

Identificar situações práticas em ciência de dados nas quais uma análise causal é necessária, ainda que os dados disponíveis sejam observacionais.
